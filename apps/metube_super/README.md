# MeTube Super

The server owner's edition, for Android. Downloads stay on the server; the
library merges the server's `/history` with what is on the phone. Streams from
the server, with tags, subscriptions, folders, transcripts, batch downloads and
optional sync.

Built on `mt_core`, `mt_media`, `mt_ui` and `mt_transcripts`.

```bash
flutter test --no-pub
flutter build apk --debug
```

See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for how the pieces fit. Releases and screenshots are in the [main README](../../README.md).
